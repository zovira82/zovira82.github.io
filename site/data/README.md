# 数据监测底表与在线数据库说明

`region-database.js` 是数据监测页的完整本地底表，也是首次导入在线数据库时使用的种子数据。当前包含 11 个县市区的 321 条观测记录，以及全国石漠化变化、调查期、省级净减少和不同程度石漠化变化等 32 条图表记录。

页面优先读取 Supabase 的 `monitoring_data` 表中“已核验且已发布”的记录；在线读取失败、表尚未初始化或对应范围无在线记录时，自动使用本地底表，不显示空白页面。管理后台可以新增、编辑、核验、发布、撤回和删除数据。

## 初始化步骤

1. 在 Supabase SQL Editor 执行 `database/数据监测数据库_正式迁移.sql`。
2. 使用原管理员账号登录 `/admin/`。
3. 打开“数据监测”，点击“导入当前底表”。
4. 后续在后台维护数据；只有“已核验且已发布”的记录会进入前端。

现有 `messages` 留言表和留言审核功能不会被迁移脚本修改。

## 当前边界

- 调研范围固定为 11 个县市区，不再沿用旧版本的西畴、广南、威宁、晴隆、长宁等范围。
- 已对 2020—2025 年公开统计公报完成一轮集中检索，补入可形成跨地区对比的 GDP、GDP 增速、常住人口、三次产业结构、粮食产量、森林覆盖率和旅游接待量等主干数据。
- 对比检索仅开放至少覆盖 2 个调研地区的同指标、同单位数据；单地区孤立指标保留在底表，但不进入比较指标列表。
- 合江县人口记录为户籍人口，不与其他地区的常住人口直接合计。
- 布拖县 GDP 暂为 2023 年已核验值；2024 年精确值待补齐。
- “已核验”表示已核对到当前记录所列公开来源，不等同于第三方审计。
- 地图使用公开行政区划边界绘制三省轮廓，11 个点位按县级行政中心坐标标注；生成式图像仅作为低对比地形纹理，不承担边界或点位精度。

## 后续复核顺序

1. 跟进尚未公开或未检索到完整公报的年份，重点复核布拖县和赫章县缺口。
2. 补齐森林覆盖率、水土流失治理、石漠化治理与土地利用指标。
3. 收集特色产业、生态旅游、林下经济等生态经济指标。
4. 保存来源发布时间、页面快照、口径变更和复核记录。
